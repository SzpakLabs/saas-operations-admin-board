# Roadmap: SaaS Ops Admin Dashboard

**Created:** 2026-06-08
**Granularity:** Coarse

## Phase 1 - Publishable Dashboard Baseline

Goal: Ensure login, main navigation, and the overview screen are reliable and visually credible.

Requirements: ACCESS-01, ACCESS-02, OPS-01, PACK-03

Deliverables:

- Smoke-test login and main dashboard route.
- Verify overview KPIs, charts, alerts, activity, and at-risk account sections.
- Fix crashes, broken navigation, or obvious first-screen layout issues.
- Capture or identify the first acceptable screenshot.

Exit Criteria:

- User can sign in and understand the SaaS ops story within 60 seconds.
- No obvious desktop layout issue blocks publication.

## Phase 2 - Operations Workflow Completeness

Goal: Verify the supporting admin routes and local-state workflows.

Requirements: OPS-02, OPS-03, OPS-04, OPS-05, OPS-06

Deliverables:

- Verify customers, customer detail, subscriptions, tickets, alerts, and settings routes.
- Confirm at least one ticket action changes local state.
- Confirm alert actions change local state.
- Keep fixes scoped to demo blockers.

Exit Criteria:

- Main routes work for a short recorded demo.
- Local-state actions are visible and understandable.

## Phase 3 - Portfolio Packaging And Deployment

Goal: Package and publish the demo for outreach.

Requirements: ACCESS-03, PACK-01, PACK-02

Deliverables:

- Update README or portfolio notes.
- Run the strongest practical short check.
- Deploy or prepare deployment.
- Add live URL or deployment notes.

Exit Criteria:

- Demo is ready to share in proposals.
- Documentation explains setup and value clearly.
