# Research: Features

**Project:** OpsBoard SaaS Operations Admin Dashboard
**Date:** 2026-06-08

## Table Stakes For This Demo

- Fake login with obvious demo credentials and no private setup.
- Dashboard overview with revenue, churn, customer health, tickets, alerts, and activity.
- Customer list with search, filters, status/health signals, and detail navigation.
- Customer detail view with subscription, invoices, tickets, and notes.
- Subscription view with plan, status, billing, trial, and MRR context.
- Ticket workflow with visible status changes.
- Alert workflow with investigate, resolve, or dismiss actions.
- Settings page that makes the product feel like a real internal tool.
- README or portfolio notes with problem, solution, stack, setup, deployment, and demo script.
- Public deployment path requiring no environment variables.

## Differentiators To Keep Lightweight

- Polished first-screen composition suitable for a portfolio screenshot.
- Realistic B2B labels, business metrics, and operational language.
- Local-state interactions that prove workflow thinking without backend cost.

## Anti-Features

- Real billing, auth, RBAC, database, or integrations.
- Deep mobile redesign.
- Broad cleanup that delays publication.
- More feature surface without improving the 60-second walkthrough.
